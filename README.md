#  Projeto Contador - Meu Primeiro Passo no JavaScript

Este é o meu primeiro projeto prático utilizando **JavaScript**, desenvolvido como parte do ecossistema de aprendizado da **DIO (Digital Innovation One)**. O objetivo principal foi aplicar os fundamentos de manipulação do DOM (Document Object Model), escuta de eventos e lógica condicional.

---

##  Demonstração

O projeto consiste em um contador interativo e totalmente estilizado onde o usuário pode incrementar ou decrementar valores de forma dinâmica através de cliques.

---

##  Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível do cabeçalho e container.
* **CSS3:** Estilização moderna com Flexbox, sombras suaves (`box-shadow`), gradientes e efeitos físicos de clique nos botões (`:active`).
* **JavaScript (ES6+):** Lógica do contador, manipulação do estado da tela e resolução de desafios de código.

---

##  Desafios Concluídos

Durante o desenvolvimento, implementei com sucesso os seguintes desafios de lógica e boas práticas:

1. **Eventos Independentes com `addEventListener`:** Substituição de atributos inline no HTML por escutas de eventos dinâmicas e isoladas no script usando Arrow Functions.
2. **Controle de Limites Operacionais:** O contador possui limites rígidos de funcionamento. O botão de adicionar `(+)` é desativado automaticamente ao atingir **10** e o botão de subtrair `(-)` é desativado ao atingir **-5**.
3. **Feedback Visual Dinâmico:** Aplicação de estilização condicional via script (operador ternário). Caso o contador assuma um valor negativo, o número central passa a ser exibido na cor **vermelha**, retornando à cor padrão ao voltar a zero ou valores positivos.
4. **Código Limpo (Refatoração):** Otimização do código original utilizando recursos modernos do JavaScript como operadores de incremento/decremento (`++` / `--`), Arrow Functions e operadores ternários para reduzir repetições.
